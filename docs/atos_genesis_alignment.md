# Atos alignment: what is public fact, and what is project inference?

**Important:** This is an independent portfolio prototype inspired by public Atos materials. It is not an Atos product, internal architecture, or customer deployment.

## Publicly stated direction (checked 28 October 2026)

1. Atos announced **Atos Genesis Intelligence** on 26 October 2026 as an enterprise AI suite intended to help organizations move from experimentation to production. The announcement describes sovereign data management, AI capabilities, secure orchestration and governance.
2. The same announcement describes **Atos Codex (Center of Operations and Data EXcellence)** as connecting operational data, context, cybersecurity controls and AI reasoning to governed actions. It also describes an operational ontology containing entities, relationships, rules, permissions and possible actions.
3. Atos describes the Genesis Intelligence suite as including a data foundation with quality, cataloguing, lineage and traceability; model routing and cost optimization; a Small Language Model Factory; a governed agent portal; and flexible deployment options including public cloud, sovereign cloud, on-premises and air-gapped environments.
4. Atos's **Sovereign Agentic Studios** describe a structured service journey: identify valuable opportunities, build and validate workflows, industrialise proven use cases, then operate and optimise them. Their stated controls include governance, cybersecurity, FinOps and human-in-the-loop oversight.
5. Atos Group's tech strategy discusses AI as an industrial capability and the future of services as “Service-as-Software,” with agents doing repeatable, data-intensive work while humans retain intent, judgment, quality and accountability.
6. Atos and Microsoft announced in June 2026 that they were expanding collaboration, rolling out Microsoft 365 Copilot and using Copilot Studio and Microsoft Foundry to design, build and operate agents for Atos functions and customers, with governance and security controls.

## Why this project fits the job description

The target AI Consultant / AI Solutions Analyst job description asks for business-process discovery, AI use-case prioritisation, practical prototyping, Power BI, API/JSON/connector awareness, evaluation of grounding and relevance, and stakeholder communication. CriticalOps lets a candidate demonstrate that whole path in a small bounded case.

| Public Atos theme | Demonstration in this project | Boundary |
|---|---|---|
| Opportunity diagnosis | Weighted use-case readiness scoring and risks/next steps | Illustrative rubric, not an Atos method |
| Operational data/context | Synthetic asset, incident and knowledge-article context | Not a real enterprise data foundation |
| Operational ontology | Explicit entities, relationships, rules and permitted actions in architecture doc | Small conceptual model, not a full ontology platform |
| Agent/AI workflow | Triage, retrieve evidence, draft response, request human review | Offline deterministic baseline by default; optional LLM draft mode; not an autonomous agent |
| Governance and sovereignty | Human review, audit log, permissions discussion, deployment trade-offs | No production identity/security implementation |
| Data and value measures | Evaluation report and Power BI-ready metrics | Synthetic results are not business outcomes |
| FinOps / frugal AI | Design proposal to record latency, model choice and cost for future adapters | Actual LLM token/cost telemetry is not implemented |

## Interview phrasing

“I reviewed Atos's public direction around Genesis Intelligence, Codex and the Sovereign Agentic Studios. I didn't try to recreate an Atos platform. I built a small independent example of the discipline those themes imply: identify a high-value workflow, assess readiness, retrieve approved evidence, propose a controlled next step, retain human approval, and measure quality and operational outcomes.”
